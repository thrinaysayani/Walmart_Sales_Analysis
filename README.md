# 🛒 Walmart Sales Data Analysis using Python & SQL

## 📌 Project Overview

This end-to-end **Data Analysis** project uses **Python** and **SQL** to analyze **Walmart sales data** and uncover valuable business insights.
It demonstrates data cleaning, advanced SQL querying, and analytical problem-solving to support data-driven decision-making.


---

## 🎯 Objectives

* Clean and preprocess raw Walmart sales data.
* Generate a structured dataset for analysis.
* Store cleaned data in a MySQL database.
* Perform Exploratory Data Analysis (EDA).
* Solve real-world business questions using SQL.
* Derive actionable insights from sales transactions.

## 📊 Dataset Information

The dataset contains Walmart sales transaction records with the following attributes:

* Invoice ID
* Branch
* City
* Product Category
* Unit Price
* Quantity
* Date
* Time
* Payment Method
* Customer Rating
* Profit Margin
* Total Price

---

## 🔹 Data Cleaning Process (Python)

The notebook performs the following preprocessing steps:

* Imported required Python libraries.
* Loaded the Walmart sales dataset.
* Explored the dataset structure.
* Checked descriptive statistics.
* Identified duplicate records.
* Removed duplicate entries.
* Checked for missing values.
* Removed rows containing null values.
* Converted the `unit_price` column from string to numeric format.
* Created a new `total_price` column.
* Exported the cleaned dataset.
* Connected Python to MySQL using SQLAlchemy.
* Uploaded the cleaned dataset into a MySQL database.

---

## 📈 Exploratory Data Analysis (EDA)

Basic SQL exploration includes:

* View all records
* Count total transactions
* Count distinct branches
* Find minimum and maximum quantities sold

---

## 📌 Business Problems Solved Using SQL

This project answers several real-world business questions, including:

1. Find different payment methods, number of transactions, and quantity sold.
2. Identify the highest-rated product category in each branch.
3. Determine the busiest day for every branch.
4. Calculate total quantity sold by payment method.
5. Compute minimum, maximum, and average ratings by city and category.
6. Calculate total profit generated by each product category.
7. Find the most preferred payment method in each branch.
8. Categorize transactions into Morning, Afternoon, and Evening sales shifts.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/thrinaysayani/walmart_sales_analysis.git
```

Navigate into the project folder:

```bash
cd walmart_sales_analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## 🚀 How to Run

### Step 1

Open the Jupyter notebook:

```bash
jupyter notebook project.ipynb
```

### Step 2

Run the notebook to:

* Clean the data
* Generate the cleaned CSV
* Upload the dataset to MySQL

### Step 3

Execute the SQL scripts:

* `EDA.sql`
* `SQL_Queries.sql`

using MySQL Workbench or any MySQL client.
